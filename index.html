Hybrid Trading Decision System
in development
Architecture
Signal generation layer (statistical + ML) → market regime classifier → risk-adjusted position sizing → execution simulator.
Problem
Strategies tuned on backtests alone tend to decay quickly out-of-sample once market regimes shift underneath them.
Solution
Gate strategy exposure by a detected market regime and its confidence, rather than applying one static rule set across all conditions.
Technologies
Pythonscikit-learnXGBoostPandasNumPy
Performance
Backtest metrics pending final computation.
Lessons learned
Regime detection adds real value only when paired with strict guardrails on confidence - an unfiltered signal is worse than none.

Calendar Anomalies - Research Engine
research · in preparation
Architecture
NIFTY 50 daily OHLC ingestion (2007–2024) → calendar/event tagging (day-of-week, month, Union Budget windows) → Market Model regression → robustness suite.
Problem
Determining whether calendar-based return anomalies in Indian equities persist once market-wide risk is properly controlled for.
Solution
A Market Model event-study pipeline covering day-of-week effects, monthly seasonality, and Union Budget announcement effects.
Technologies
PythonPandasstatsmodelsNumPy

Win rate and Sharpe ratio pending final computation.
